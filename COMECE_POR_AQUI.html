Como abrir o aplicativo

  1. Instale Node.js 22 e abra um terminal na pasta deste pacote.
  2. Execute npm ci e depois npm run dev.
  3. Abra o endereço informado no terminal. Sem Firebase configurado, entre na demonstração com dados fictícios.
  4. O menu Identidade visual reúne as artes; Infraestrutura e consumo concentra o monitoramento.

Para conectar dados reais, siga o guia técnico. Este pacote é um piloto e não foi implantado na sua conta.
